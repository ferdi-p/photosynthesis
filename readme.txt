Code and figures for 

"A model for heat and light stress in photosynthesis"

Pfab et al (2025)

Code:

Fig_....nb: create the figures in the paper.

model.wl: sets up the model
parameters.wls: defines parameter values
styles.wl: defines styles for plotting

combine_packages.wls: loads the packages together

load_..._data.wl: loads the datasets we compare the model to

fit_arrhenius.nb: fits the temperature-Fv/Fm curve
